# Shared state sheet — modals and drawers

- Use a scrim, labelled heading, close button, Escape handling, and focus return.
- Drawers are for inspectable context; modals are for a single decision or confirmation.
- Keep the decision rail sticky only while the decision is active. Never hide the primary action below the fold.
- Destructive or irreversible actions require a second explicit confirmation and state the affected record.
